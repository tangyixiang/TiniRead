# 系统架构与快速上手指南

本文档用于测试文档大纲层级解析、代码高亮渲染与引用块样式。

## 1. 系统模块架构

TiniRead 采用客户端原生与前端渲染分离架构：

- **桌面底座**：Tauri 2.0 原生容器，负责跨平台系统窗口、文件系统与原生事件处理；
- **存储引擎**：SQLite 本地嵌入式数据库，维护历史记录与文档高亮标记；
- **渲染引擎**：React 19 + Tailwind CSS，支持所见即所得双向无缝编辑。

### 1.1 模块分层关系

数据流由底层文件系统向上单向传递至渲染层：

```text
[本地文件系统] ──> [Rust 原生守护模块] ──> [Tauri 进程间事件通信] ──> [React 渲染层]
```

### 1.2 跨平台特性支持

针对 macOS 与 Windows 进行差异化适配：

- macOS：支持原生无边框窗口拖拽、Traffic Light 交通灯按钮内边距沉浸式适配；
- Windows：支持原生窗口控制组件与标准边框。

## 2. 核心代码块渲染测试

### 2.1 Rust 后端监听实现

```rust
use notify::{Config, RecommendedWatcher, RecursiveMode, Watcher};
use std::path::Path;

pub fn start_watch(path: &Path) -> Result<(), String> {
    let mut watcher = RecommendedWatcher::new(|res| {
        if let Ok(event) = res {
            println!("检测到文件变动: {:?}", event.paths);
        }
    }, Config::default()).map_err(|e| e.to_string())?;

    watcher.watch(path, RecursiveMode::NonRecursive)
        .map_err(|e| e.to_string())?;
    Ok(())
}
```

### 2.2 前端事件监听对接

```typescript
import { listen } from '@tauri-apps/api/event';

export function setupWatcher(callback: (path: string, content: string) => void) {
  return listen<{ path: string; content: string }>('file-changed', (event) => {
    const { path, content } = event.payload;
    callback(path, content);
  });
}
```

### 2.3 终端快速编译命令

```bash
# 启动开发服务器
npm run tauri:dev

# 执行生产环境构建
npm run tauri:build
```
