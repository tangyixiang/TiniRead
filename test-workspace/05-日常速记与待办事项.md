# 日常速记与即时备忘录

这是一个轻量简短的备忘文档，非常适合用来测试：
1. 文档快速切换与大纲默认收起；
2. 外部程序修改该文件时，TiniRead 的实时热重载（Live Reload）；
3. 自动保存与未命名保存。

## 1. 临时便签

- 评审本周前端组件重构方案
- 确认 SQLite 本地数据库索引性能
- 准备下一阶段 PDF 导出原型

## 2. 外部修改测试命令

您可以在另一个终端窗口执行如下命令，观察 TiniRead 窗口中该文档的实时无缝刷新：

```bash
echo "\n- [x] 外部同步测试项已于 $(date +%H:%M:%S) 写入" >> test-workspace/05-日常速记与待办事项.md
```

## 3. 会议记录要点

- 时间：每周一上午 10:00
- 议题：沉浸式 Markdown 阅读器核心指标优化
- 结论：始终坚持阅读体验优先，交互与文案保持极致克制
