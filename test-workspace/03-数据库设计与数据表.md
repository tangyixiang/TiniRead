# 数据库设计与数据表结构

本文档用于测试 Markdown 数据表格排版、待办清单解析以及嵌套列表渲染。

## 1. 核心数据表结构定义

系统在本地 SQLite 数据库中维护两个核心业务表，记录阅读进度与文本高亮。

### 1.1 最近访问记录表 (recent_documents)

| 字段名称 | 数据类型 | 约束条件 | 字段说明 |
| :--- | :--- | :--- | :--- |
| id | TEXT | PRIMARY KEY | 全局唯一标识符 (UUID v4) |
| file_path | TEXT | UNIQUE NOT NULL | 磁盘绝对规范路径 |
| file_name | TEXT | NOT NULL | 文档文件名（包含扩展名） |
| title | TEXT | NOT NULL | 文档主标题（通常为首个一级标题） |
| snippet | TEXT | NOT NULL | 前 80 字符正文内容摘要 |
| word_count | INTEGER | NOT NULL DEFAULT 0 | 全文字符数量统计 |
| scroll_progress | REAL | NOT NULL DEFAULT 0.0 | 退出时的阅读滚动百分比 (0-100) |
| last_opened_at | INTEGER | NOT NULL | 最近一次打开的时间戳（秒级） |

### 1.2 文档高亮标记表 (document_highlights)

| 字段名称 | 数据类型 | 约束条件 | 字段说明 |
| :--- | :--- | :--- | :--- |
| id | TEXT | PRIMARY KEY | 高亮条目唯一标识 |
| file_path | TEXT | NOT NULL | 所属文档绝对路径 |
| selected_text | TEXT | NOT NULL | 用户选中的高亮文本片段 |
| color | TEXT | NOT NULL | 高亮样式分类 (hl-yellow 等) |
| note | TEXT | NULLABLE | 用户附加批注（可选） |
| created_at | INTEGER | NOT NULL | 创建时间戳 |
