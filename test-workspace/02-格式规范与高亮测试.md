# 格式规范与高亮色彩测试

本文档用于全面验证行内代码配色、超链接交互以及五色文本高亮标记。

## 1. 科技钴蓝行内代码测试

行内代码在浅色、暖色和暗色主题下均经过对比度微调，不再采用刺眼的紫色。

- 环境配置文件路径：`iot-factory-hot/.env` 以及 `config/production.local.json`
- 数据库连接串测试：`postgresql+psycopg2://postgres:secret123@127.0.0.1:5432/tiniread_db`
- 环境变量键名：`DATABASE_URL`、`REDIS_STREAM_ENABLE`、`HIKIP_PORT`
- 包管理命令：`npm install`、`cargo build --release`、`git status -s`

## 2. 外部超链接样式测试

超链接支持主题自适应科技蓝与下划线交互效果：

- 访问 [Rust 官方网站](https://www.rust-lang.org) 查阅底层系统编程指南；
- 查阅 [Tauri 2.0 文档](https://tauri.app) 获取桌面端架构设计规范；
- 浏览 [Tailwind CSS 官方文档](https://tailwindcss.com) 了解原子类设计体系。

## 3. 五色高亮标记测试

软件支持五种主题高亮标记，选中文字即可通过浮动工具栏添加或移除：

- 经典黄色标记：==yellow:这是采用默认金黄色标记的核心关键定义==
- 清新绿色标记：==green:这是表示校验通过或成功状态的绿色高亮标记==
- 沉稳蓝色标记：==blue:这是表示技术要点或参数项的科技蓝高亮标记==
- 醒目粉色标记：==pink:这是表示需要重点排查或警示的粉色高亮标记==
- 薰衣草紫标记：==purple:这是用于知识归纳或扩展阅读的紫色高亮标记==

## 4. 基础文本修饰

- **粗体强调效果**：在排版中强化视觉重心；
- *斜体说明效果*：用于标注术语或辅助引述；
- ***粗斜体叠加***：用于最高级别的情调词汇；
- ~~已废弃或过期的特性说明~~：展示删除线样式。
